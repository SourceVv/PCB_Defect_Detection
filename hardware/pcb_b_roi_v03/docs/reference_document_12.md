# ROI算子ABI3对接说明

此文件供A/C核对候选接口，不代表已向其他成员发送消息或已获全组冻结确认。

## A提供给B/C

- 已经对齐到参考坐标系的单通道uint8图像，当前冻结样本为宽2533、高1900。
- 有明确版本的ROI列表，每个(name,box,enabled)，box左闭右开。
- 独立期望mask与每ROI前景像素数。像素规则为严格>阈值，可选择先反相。
- 缺件分类所需的其他特征与阈值继续独立定义，避免把所有位号都改用面积分类。

## B交付给C

- 同次导出的pcb_roi.bit/.hwh，硬件ABI3。
- RoiDriver：recover→configure→transfer→read_results。
- AXIS32，整帧一次TLAST，无逐行padding；几何与总字节受严格检查。
- 原灰度直接输入，invert=true时由PL反相；roi_enable=true时由PL生成ROI并集mask。
- 单ROI前景面积、输出并集前景数、有效输入像素数和包状态。单ROI面积可重复计入重叠像素，并集不重复。
- 地址按HWH实例名解析；本次cfg/ctrlGPIO相较旧版发生地址互换，C不应沿用旧手写地址。

## 需要统一的边界

定位后应保证图像坐标与配置一致。当前静态黄金图的验证不能替代新拍照片的定位/泛化测试。latest17与frozen16的索引不同，结果按本profile的名称配对。反相只做一次，输入给驱动的仍是原uint8灰度。

候选版本保留ABI0.2基线，直到系统端完整回归通过。长时稳定性、相机端到端周期和完整分类准确率应单独留实际证据。
