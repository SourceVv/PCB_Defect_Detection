# 示例数据和评测方法

`data/reference` 包含正常参考照片，`data/development/s01` 包含6张开发照片。`research/baseline/data` 保存原算法使用的18张开发照片与标签。它们已经参与算法开发与调试，不能重新命名为独立测试集。

原始板况记录包括：B02的LED7、LED5、U5、X2、SW2缺件；B03的X1、U2、U6、U4缺件；B04的MIC1、C13、R12、C20、L2、U3、U1缺件；B05的U1、U5旋转180度；B06的C14、C17歪斜，以及当前单张平面图不作可靠高度判定的翘起项目。不同拍摄批次对应实物状态应再次核对。

建议比赛评测另建 `evaluation` 数据集，记录板型、板号、拍摄条件和人工真值。每个位置分别统计缺件、焊反、歪斜；同时列出误报、漏检、待确认及不适用项目。未核对的位号不能用默认正常补齐。

照片分辨率、板子位置和面内旋转可以不同；最小元件、丝印和方向标记仍需有足够成像细节。强反光、遮挡、失焦或明显立体变形可能使配准和封装分析失败。
