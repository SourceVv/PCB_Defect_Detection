# 整机验收与实验记录

当前没有PYNQ实测数据。本目录规定后续记录格式；PC回归测试在pcbinspection/tests，PC输出在pcbinspection/outputs。

## 验收顺序

| 关卡 | 通过标准 | 负责人 |
|---|---|---|
| 板卡启动 | 镜像启动、Jupyter可访问、点灯正常 | B/C |
| DMA回环 | 短数组及固定图像往返一致，有超时处理 | B/C |
| 单算子 | 真实PL结果与参考一致，保存首个差异信息 | A/B/C |
| 缺件闭环 | 采集、定位、PL处理、判断与显示可重复执行 | A/C |
| 独立测试 | 冻结参数后新批次采样，报告漏检、误报、invalid/uncertain | A/C |
| 稳定与性能 | 连续运行至少30分钟，记录帧数、错误和整机延迟 | B/C |

## 每轮记录至少包含

- 日期、负责人、Git提交SHA、源码和配置版本。
- bit/hwh文件哈希、Vivado版本、板卡镜像、依赖与相机设置。
- 输入图或数组哈希、传输格式、实际输出与比对结果。
- 完整复现命令、失败现象、恢复方式；无板端日志时不填“上板通过”。
- 软件时间、DMA往返、PL算子与整机时间的测量口径；未测值写未测。

冻结版本时提交小型汇总CSV和报告；大视频、日志和二进制输出作为版本附件管理。不要把板号绑定的开发成绩当成任意PCB泛化成绩。
