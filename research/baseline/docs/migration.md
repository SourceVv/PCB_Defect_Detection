# 从A成员原包到0.3.0的整理记录

原始来源为用户提供的`pcb_inspection.zip`。此版本在独立目录建立，原压缩包与解压档案保留；旧作者电脑上的绝对路径不再作为运行条件。

## 已整理

| 原问题 | 本版处理 |
|---|---|
| 路径写死用户名和盘符 | 配置内参考路径以配置文件为基准；命令行明确传参 |
| 单文件脚本相互sys.path插入 | 使用src布局、pyproject和可安装Python包 |
| 标签重复、旧字典缺U4 | 从实物缺陷清单整理252项缺件真值，评价统一读取CSV |
| 空白图仍报缺件 | invalid图像停止分类 |
| 倾斜位置误显示present | 未实现任务返回uncertain及原因 |
| fpga参数悄悄跑软件 | 未实现后端明确抛NotImplementedError |
| 缩放后位移与标注坐标错误 | 在配置尺寸定位，再映射回原图绘制 |
| 黄金包版本落后且只比状态 | 按当前配置生成，核对特征、面积、数组和源文件哈希，支持读实际PL输出 |
| 中文图片路径读取不稳 | 使用imdecode/imencode处理路径 |
| 代码和数百张探索图混放 | 正式目录只保留可运行核心、样例、标签与文档 |

## 保留与未完成

保留原0.2.0的14缺件ROI、特征、阈值数学定义。没有重新调参或承诺新相机、新批次效果。ORB实现和随机数种子被固定为可重复路径；通过回归测试确认现有252项结果不变。

没有迁入每个历史实验脚本，也没有重写焊反、倾斜或DMA工程；需要时从原档案取出、改为参数化工具、加测试，再进入正式仓库。C24倾斜、C32翘起的真值冲突需实物确认。LED5/LED7未进入当前检测范围。

`board_defects.csv`转录原清单23条记录；`component_truth.csv`只用于存在/缺件任务，因此B05上反装但存在的U1/U5仍标为present。这不等于方向合格。

## 依赖复现范围

PC精确依赖放在requirements-pc.txt；本地以Python 3.14.6验证。未来PYNQ Linux/ARM依赖需要独立锁定，不应强行安装PC轮子。跨系统浮点/ORB有差异时检查实际结果；CI尚须上传后执行。
