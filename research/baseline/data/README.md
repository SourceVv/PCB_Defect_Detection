# 数据与标签

S01：六块固定实物板，每块三张开发图，共18张。照片原样复制，不重新编码，`labels/photos.csv`记录SHA256，可检查传输后是否一致。

`board_defects.csv`来自原包器件情况文本表；它是现有标注的转录，不是新做的实物鉴定。

`component_truth.csv`对当前14个缺件位置提供18×14=252项真值。默认存在仅适用于这14个位号和此批现有标注；不能扩展到未知板子或新位号。所有照片用途都标为development。

新增S02时：新建raw/S02，记录照片清单，人工确认器件状态，创建该批component_truth_S02.csv，再执行评价。配置冻结后拍摄的数据才可用于独立测试。若根据S02再调参数，应再拍新的最终测试批次。

未包含原始DNG、旧标签文件、下载副本、历史裁图。新样本的获取许可、拍摄设置、用途与板号应一并记录。
